本版修正
1. 民國年份只接受 1～199，西元接受 1912～2500；OCR 誤讀的 1115、3026 不會帶入，也不能通過送出檢查。
2. 排除電子發票期別、兌換及截止日期。
3. 購買票品證明單／免用統一發票收據可辨識為收據；郵局英文標題也可協助判定。
4. 支援文字與金額分行、表格另一側、稅額欄勾選文字、總計同列的數量與金額。
5. 整張原照片加上下半部分區重讀，對相互衝突的欄位留空提示確認。
6. 增加框選範圍，原照片下載保持原圖；只裁切辨識用畫面。
7. 保留手填欄位；重讀時可更新程式先前帶入、且尚未被你改動的欄位。
8. 日期欄限制寬度，避免手機日期框超出畫面。

照片辨識
先轉正照片，按「框選憑證範圍」，先點左上角、再點右下角，按「套用框選」。
盡量框住紙張，把鍵盤和桌面排除，再按辨識照片。
預設「整張＋上下分區」會辨識三次，較慢；長條電子發票上半部常是日期與號碼、下半部常是金額。
若仍缺欄位，可改辨識範圍；特殊版面可另外框選缺漏區域，手填內容會保留。
下載原照片仍是原始檔，不是裁切後的圖。
辨識失敗時已完成的區域結果仍會保留，沒有把所有欄位默默填好。

更方便的文字備援
若照片辨識仍差，可用手機相簿的文字辨識功能複製憑證文字，貼到「辨識文字／手動貼文字」，按「從文字預填欄位」。
手寫、圓形郵戳和模糊印字仍可能需要手填。不以 5% 猜測未辨識到的稅額。
收據只有總額且無稅，先確認憑證種類為收據，再勾「我確認這張收據無稅」，會以總額填支出、稅額填 0。
只在已辨識到免稅／免用發票文字且有總額時自動帶入稅額 0。

四條內建規則
購買票品證明單 → 項目「郵寄資費」
黑貓 → 項目「宅配運費」
百康 → 備註「百康」
蝦皮 → 備註「蝦皮」
忽略關鍵字裡的空格和換行，但 OCR 沒读到关键字仍不能套用。
頁面下方可新增、刪除、匯出、匯入規則；保留已有手填內容，衝突時提示。
規則保存在當前瀏覽器。升級會保留既有規則；刪除內建規則後不會每次重整再加回。

登錄與送出
不拍照也能手填收入／支出。收入為含稅總額（稅欄記其中稅額），支出為未稅金額加稅。
收入 V 收訖、支出 C 付訖、空白未收付；已收付請填實際收付日。
代收墊單選：空白／潘／黃／張／吳／lab。
暫無憑證可選未開發票／暫無憑證，之後在財務補資料。
確認日期、號碼、金額、狀態後勾確認並送到原 Google 表單。
看到 Google「已記錄您的回覆」才算確認成功。若內嵌頁面受阻，可用「開啟預填表單」再提交。
照片在裝置內處理，不上傳Google或GitHub；首次使用需連網下載OCR模型。
未送出的欄位不保證關閉網頁後保留。

實際測試限制
已測試原照片、多區域辨識結果解析、異常年份、郵局收據、四條規則、手填保留、收入與表單欄位映射。
實際照片中，A4 與全家金額解析改善；郵局讀到總額 80、收據種類、郵寄資費，但郵戳日期仍不可靠。
其他照片仍有號碼、金額或日期缺漏，不能視為完整自動辨識。手寫三聯式與手寫收據仍需人工核對。
沒有提交真實 Google 測試資料，尚未在你的手機實測新版。
